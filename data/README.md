# Data

Everything under `external/` and `processed/` is **git-ignored** — it is large
and fully re-creatable from scripts. Do not commit raw DNS/RANS data.

## `external/` — reference DNS

Downloaded by `scripts/fetch_dns_data.sh` from the public
[para-database-for-PIML](https://github.com/xiaoh/para-database-for-PIML)
(Xiao et al. 2020, `Re_H = 5600`). Layout:

```
external/pehill-5-cases-DNS/case_<slope>/dns-data/
    mean_files.dat    (N,6)  x/H, y/H, U/Ub, V/Ub, W/Ub, p/(ρUb²)   [CONFIRMED]
    rms_files.dat     (N,6)  x/H, y/H, + second-order statistics     [PROVISIONAL]
    rms_files1.dat    (N,6)  x/H, y/H, …, <u'v'>/Ub² in last column  [<u'v'> CONFIRMED]
    rms_files2.dat    (N,5)  x/H, y/H, + higher-order terms           [PROVISIONAL]
```

Hill slopes: `case_0p5, case_0p8, case_1p0, case_1p2, case_1p5`
(`case_1p0` is the standard geometry matching the baseline RANS case).

Column semantics were established by inspection, not assumption — see
`analysis/01_inspect_dns.py` and the notes in `src/mlrans/dns.py`. Only the mean
fields and the Reynolds shear stress `<u'v'>` are relied upon downstream; the
individual normal-stress columns remain provisional pending cross-check against
the source paper.

### `external/_ofrepo/` — provided OpenFOAM cases (meshes + co-located DNS)

Sparse blob-filtered checkout (~57 MB) of `pehill-5-cases-OpenFOAM` from the
same repository, fetched by `scripts/fetch_dns_data.sh openfoam`. Each geometry
ships a `polyMesh` (the RANS-comparable coarse mesh encoding the α hill shape)
plus DNS fields already interpolated onto that mesh: `UDNS` (mean velocity) and
`TauDNS` (Reynolds-stress tensor). These meshes are the basis of the
multi-geometry RANS runs (`scripts/run_ml_cases.sh` → `cases/ml_runs/`, both
git-ignored). Coordinates are in H units (H = 1), Ub = 0.020188, Re_H = 5600.

Note: `TauDNS` read via VTK/pyvista uses VTK symmTensor order
`(xx, yy, zz, xy, yz, xz)`, so ⟨u'v'⟩ is component index **3** (not 1).

### `external/mcconkey-dataset/` — cross-flow dataset (McConkey et al. 2021)

Extracted from the Kaggle archive `ryleymcconkey/ml-turbulence-dataset`
(McConkey, Yee & Lien, *Scientific Data* 8, 255, 2021). Provides k-ω SST RANS
fields (`komegasst/`) and co-located DNS/LES labels (`labels/`, incl. the
anisotropy tensor `b`) for several separated flows: periodic hills (`PHLL`, the
same Re=5600 α-sweep), curved backward-facing step (`CBFS`), parametric bumps
(`BUMP`), converging-diverging channel (`CNDV`), and square duct (`DUCT`, not
used). Fields are flat per-cell `.npy` arrays. Used by `analysis/16_crossflow.py`
for the cross-flow generalisation test (`src/mlrans/mcconkey.py` is the loader).
The periodic-hill cases are all Re=5600, so this dataset does not add
Reynolds-number variation for that flow. Git-ignored; the 6 GB source `.zip` can
be deleted after extraction.

## `processed/` — derived datasets

`pehill_features_targets.(parquet|csv)`: the per-cell feature/target table over
all 5 geometries, built by `analysis/03_build_dataset.py` (features + β_nut +
`wellposed` flag + a `case` group column). Regenerated by the analysis scripts;
safe to delete.
