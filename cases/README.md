# OpenFOAM cases

## `periodicHill_kOmegaSST` — baseline steady RANS

Steady incompressible RANS (`simpleFoam`) with the **k-ω SST** closure on the
canonical periodic hill, at **`Re_H = 5600`** to match the DNS reference
database (Xiao et al. 2020).

Derived from the OpenFOAM v2312 tutorial
`incompressible/pimpleFoam/LES/periodicHill/steadyState`, with the following
deliberate changes:

| Change | From (tutorial) | To (this case) | Reason |
|---|---|---|---|
| Turbulence model | Spalart–Allmaras | **k-ω SST** | project baseline closure; exposes `k`, `ω`, `ν_t` |
| Viscosity `ν` | 2.643e-6 (`Re≈10595`) | **5.0e-6 (`Re=5600`)** | match the DNS database |
| Spanwise cells | 80 | **1** | mean flow is spanwise-homogeneous → quasi-2D RANS |
| `div(phi,U)` | `Gauss upwind` | **`linearUpwind grad(U)`** | 2nd order; avoid smearing separation |
| Pressure–velocity | SIMPLEC, U-relax 0.9 | **SIMPLE + under-relaxation** | avoid limit cycle; reach steady state |
| Post-processing | — | wallShearStress, yPlus, R | fields for the failure map |

**Flow is driven** by a `meanVelocityForce` (`system/fvOptions`) enforcing bulk
`U_b = 1 m/s` through the `inletCellZone` built by `topoSet`. Streamwise and
spanwise boundaries are cyclic; hill and top are no-slip walls with wall
functions (`nutUSpaldingWallFunction`, `omegaWallFunction`, `kqRWallFunction`).

### Run / clean / export

```bash
scripts/run_baseline_sst.sh      # restore0Dir → blockMesh → topoSet → renumber → simpleFoam
scripts/export_latest_fields.sh  # writeCellCentres + foamToVTK of the latest time
scripts/clean_baseline_sst.sh    # reset to the case definition (safe: case-local only)
```

Only the case *definition* (`0.orig/`, `constant/`, `system/`, `Allrun`,
`Allclean`) is version-controlled; mesh, time directories, logs, VTK and
`postProcessing/` are git-ignored (regenerated by a run).
